## 1. 平台简介

### 1.1 什么是 Qlib Web？

Qlib Web 是基于微软开源量化框架 Qlib 构建的Web端量化投资研究平台，为量化研究人员和投资分析师提供了完整的量化投资工作流支持。

### 1.2 核心功能特性

- **实验管理**: 完整的量化实验生命周期管理
- **智能配置**: 基于历史数据的参数推荐系统
- **实时监控**: WebSocket实时状态更新和系统监控
- **高级分析**: 归因分析、风险分析、情景分析等专业工具
- **团队协作**: 多用户权限管理和团队工作空间
- **数据分享**: 实验结果分享和报告生成
- **模板系统**: 预定义策略模板和自定义模板管理

### 1.3 用户角色

- **管理员 (ADMIN)**: 系统管理，用户管理，全局配置
- **管理者 (MANAGER)**: 团队管理，资源分配，高级功能
- **分析师 (ANALYST)**: 量化研究，实验执行，数据分析
- **观察者 (OBSERVER)**: 只读访问，查看实验结果

## 2. 快速入门

### 2.1 注册与登录

1. **访问平台**: 打开浏览器访问 Qlib Web 平台地址
2. **用户注册**: 
   - 点击"注册账号"
   - 填写用户名、邮箱、密码等信息
   - 验证邮箱（检查邮箱中的验证链接）
3. **用户登录**:
   - 输入用户名和密码
   - 系统验证后自动跳转到仪表盘

### 2.2 仪表盘概览

登录后您将看到主仪表盘，包含：

- **统计卡片**: 实验总数、运行状态、成功率等关键指标
- **最近实验**: 最新创建或完成的实验列表
- **快速操作**: 新建实验、导入模板等快捷按钮
- **系统状态**: 系统资源使用情况和健康状态

### 2.3 创建您的第一个实验

1. **点击"新建实验"**按钮
2. **填写基本信息**:
   - 实验名称: 如"我的第一个动量策略"
   - 描述: 简要描述实验目的
3. **配置数据参数**:
   - 股票池: 选择 CSI300 或 CSI500
   - 时间范围: 2020-01-01 至 2023-12-31
   - 特征选择: 使用默认特征
4. **选择模型**:
   - 推荐初学者选择 LightGBM
   - 使用系统推荐的默认参数
5. **配置策略**:
   - 选择 TopkDropoutStrategy
   - 设置 topk=50（选择前50只股票）
6. **开始实验**: 点击"启动实验"

## 4. 实验管理

### 4.1 实验配置详解

#### 数据配置
- **股票池选择**: 
  - CSI300: 沪深300指数成分股
  - CSI500: 中证500指数成分股
  - 全A股: 全市场股票（计算量大）
- **时间范围**: 
  - 建议至少3年数据进行训练
  - 避免包含异常市场期间（如2015年股灾）
- **特征工程**: 
  - 价格因子: close, open, high, low
  - 量能因子: volume, amount
  - 技术指标: RSI, MACD, BOLL等

#### 模型配置
- **LightGBM**: 
  - 优点: 训练速度快，效果稳定
  - 适用: 初学者和快速验证
  - 关键参数: n_estimators, learning_rate, max_depth
- **线性回归**: 
  - 优点: 可解释性强
  - 适用: 因子分析和基准测试
- **神经网络**: 
  - 优点: 非线性拟合能力强
  - 适用: 复杂策略和深度学习

#### 策略配置
- **TopkDropoutStrategy**: 
  - 每期选择预测收益最高的topk只股票
  - dropout机制避免过度集中
- **TopkAmountStrategy**: 
  - 按市值加权的topk策略
- **自定义策略**: 
  - 支持上传自定义策略代码

### 4.2 实验执行流程

1. **提交阶段**: 
   - 系统验证配置参数
   - 创建实验记录
   - 加入执行队列
2. **执行阶段**: 
   - 数据预处理和特征工程
   - 模型训练和预测
   - 策略回测和性能计算
3. **完成阶段**: 
   - 结果存储和可视化
   - 发送完成通知
   - 生成分析报告

### 4.3 结果分析

#### 性能指标
- **收益指标**: 
  - 年化收益率: 策略年化收益
  - 基准超额收益: 相对基准的超额收益
  - 累积收益: 整个回测期间的累积收益
- **风险指标**: 
  - 夏普比率: 风险调整后收益
  - 最大回撤: 最大亏损幅度
  - 卡尔玛比率: 年化收益/最大回撤
- **稳定性指标**: 
  - 信息比率: 超额收益的稳定性
  - 胜率: 跑赢基准的交易日占比

#### 可视化图表
- **累积收益曲线**: 策略和基准的收益对比
- **回撤分析图**: 历史回撤分布和持续时间
- **持仓分析**: 行业分布、个股权重等
- **归因分析**: 收益来源分解

## 7. 高级分析

### 7.1 归因分析

**功能说明**: 分解策略收益的来源，理解为什么策略能够盈利。

**使用方法**:
1. 在实验详情页选择"归因分析"标签
2. 查看不同维度的收益贡献：
   - **行业归因**: 不同行业的收益贡献
   - **风格归因**: 大小盘、价值成长等风格因子贡献
   - **个股选择**: 个股超额收益贡献
   - **时机选择**: 进出场时机的贡献

**结果解读**:
- 正值表示该因子对策略有正贡献
- 关注主要收益来源，验证策略逻辑
- 分析负贡献因子，识别风险点

### 7.2 风险分析

**VaR风险价值**:
- VaR95: 95%置信度下的最大损失
- VaR99: 99%置信度下的最大损失
- 用于设置止损位和风险控制

**回撤分析**:
- 最大回撤: 历史最大亏损幅度
- 回撤持续时间: 从开始回撤到恢复的时间
- 当前回撤: 当前距离高点的回撤幅度

**相关性分析**:
- 市场相关性: 与大盘的相关程度
- 行业相关性: 与各行业指数的相关性
- 用于评估策略的独立性

### 7.3 情景分析

**市场情景模拟**:
1. 选择"情景分析"功能
2. 设置分析参数：
   - 市场冲击幅度（如-20%）
   - 行业冲击差异
   - 时间持续期间
3. 查看策略在不同情景下的表现

**蒙特卡洛模拟**:
- 模拟次数: 建议1000次以上
- 置信区间: 通常使用95%置信区间
- 结果分析: 关注尾部风险和极端情况

### 7.4 模型诊断

**特征重要性**:
- SHAP值分析: 了解各特征的贡献度
- 特征稳定性: 评估特征的时间稳定性
- 特征相关性: 识别多重共线性问题

**模型性能监控**:
- IC衰减: 模型预测能力的时间变化
- 预测误差: 模型预测与实际的偏差
- 更新提醒: 建议模型重新训练的时机

## 10. 常见问题

### 10.1 实验相关问题

**Q: 实验为什么会失败？**
A: 常见原因包括：
- 数据时间范围设置错误（开始时间晚于结束时间）
- 模型参数设置不合理（如学习率过大）
- 股票池数据不足（选择的股票池在指定时间段没有足够数据）
- 系统资源不足（同时运行的实验过多）

**Q: 如何提高实验成功率？**
A: 建议：
- 使用系统推荐的参数范围
- 选择较长的数据时间范围（至少2年）
- 避免在系统负载高峰期提交大量实验
- 使用模板创建实验，降低配置错误风险

**Q: 实验结果不理想怎么办？**
A: 优化建议：
- 检查数据质量和特征工程
- 尝试不同的模型和参数组合
- 进行特征重要性分析，筛选有效特征
- 使用交叉验证避免过拟合

### 10.2 系统使用问题

**Q: 忘记密码怎么办？**
A: 
1. 在登录页面点击"忘记密码"
2. 输入注册邮箱地址
3. 查收密码重置邮件
4. 按邮件指引重设新密码

**Q: 如何提高系统使用效率？**
A: 建议：
- 熟练使用快捷键和批量操作
- 创建和使用模板减少重复配置
- 设置合适的通知提醒
- 利用团队协作功能分工合作

**Q: 数据安全如何保障？**
A: 系统安全措施：
- 数据传输加密（HTTPS）
- 用户权限管理和访问控制
- 定期数据备份
- 操作日志记录和审计

### 10.3 性能优化

**Q: 系统响应慢怎么办？**
A: 优化方法：
- 清理浏览器缓存和Cookie
- 使用现代浏览器（Chrome、Firefox最新版）
- 关闭不必要的浏览器标签页
- 检查网络连接质量

**Q: 如何减少实验等待时间？**
A: 建议：
- 选择合适的时间段进行实验（避免高峰期）
- 优化数据范围和模型复杂度
- 使用增量训练而非全量重训练
- 合理安排实验优先级
