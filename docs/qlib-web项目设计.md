# Qlib Web Console - 完整量化投资工作流程设计

本文档描述了 Qlib Web Console 的完整量化投资工作流程，从因子开发到回测分析的全链路设计。

---

## 系统架构概述

Qlib Web Console 提供一个完整的量化投资研发平台，包含四个核心模块：

```
┌─────────────────────────────────────────────────────────┐
│                  Qlib Web Console                      │
├─────────────────────────────────────────────────────────┤
│ ┌─────────────┐  ┌─────────────┐  ┌─────────────┐      │
│ │页面一:      │  │页面二:      │  │页面三:      │      │
│ │AI因子助手   │  │模型训练     │  │策略回测     │      │
│ │            │  │            │  │(需要因子+   │      │
│ │- 因子生成   │  │- qrun训练   │  │ 训练模型)   │      │
│ │- 因子解读   │  │- 模型管理   │  │- 回测配置   │      │
│ │- 因子库     │  │- 进度监控   │  │- 策略执行   │      │
│ └─────────────┘  └─────────────┘  └─────────────┘      │
│                                                         │
│ ┌─────────────┐  ┌─────────────┐  ┌─────────────┐      │
│ │页面四:      │  │页面五:      │  │页面六:      │      │
│ │训练列表     │  │结果管理     │  │策略部署     │      │
│ │            │  │            │  │            │      │
│ │- 训练任务   │  │- 任务列表   │  │- 实盘交易   │      │
│ │- 模型评估   │  │- 结果分析   │  │- 策略监控   │      │
│ │- 模型对比   │  │- 报告导出   │  │- 风险管理   │      │
│ └─────────────┘  └─────────────┘  └─────────────┘      │
└─────────────────────────────────────────────────────────┘
```

**核心功能模块**:
1. **页面一: AI因子助手** - 独立的因子开发工具，支持AI生成和手动编辑因子表达式
2. **页面二: 模型训练** - 独立的模型训练模块，使用qrun命令训练预测模型
3. **页面三: 策略回测** - 回测执行模块，依赖页面一的因子和页面二的训练模型
4. **页面四: 训练列表** - 管理所有训练任务，提供模型评估和对比功能
5. **页面五: 结果管理** - 统一的回测结果管理中心，分析回测表现
6. **页面六: 策略部署** - 将回测效果好的策略部署到实盘交易或模拟交易

**数据依赖关系**:
- **页面三(策略回测)** 需要依赖:
  - 页面一提供的因子表达式
  - 页面四提供的训练完成模型文件
- **页面五(结果管理)** 汇总:
  - 页面三的回测任务状态和结果
- **页面六(策略部署)** 需要依赖:
  - 页面五选择的优秀回测结果
  - 对应的模型文件和策略配置

**完整工作流程**:
1. 在页面一开发因子表达式
2. 在页面二配置并启动模型训练
3. 在页面四管理训练结果，评估模型性能
4. 在页面三使用训练好的模型进行回测
5. 在页面五分析回测结果，选择优秀策略
6. 在页面六将优秀策略部署到实盘交易

## 页面一: AI因子助手 (Factor AI Assistant)

### 功能概述
通过AI对话将用户的投资想法转换为标准的Qlib因子表达式，并提供详细的技术解读。

### 核心功能

#### 1. AI对话模式
- **自然语言输入**: 用户描述投资逻辑，如"最近涨得快的股票好"
- **智能转换**: AI解读用户想法，生成对应的Qlib因子表达式
- **详细解读**: 提供因子表达式的技术解释和计算逻辑

#### 2. 手动编辑模式  
- **因子表达式编辑器**: 支持语法高亮的代码编辑器
- **实时语法检查**: 检测Qlib因子表达式的格式错误
- **AI解读功能**: 对手动输入的因子表达式进行智能解读

### 界面设计

```
┌─ AI因子助手 ──────────────────────────────────────────────┐
│ [AI对话] [手动编辑]                                      │
│                                                         │
│ 💬 AI对话模式:                                          │
│ ┌─────────────────────────────────────────────────────┐ │
│ │ 用户: 我想要一个动量因子，过去20天涨得多的股票好      │ │
│ │                                                     │ │
│ │ 🤖 AI: 理解了！您想要的是20日动量因子。               │ │
│ │ 投资逻辑: 过去20个交易日涨幅越大，未来表现可能越好    │ │
│ │                                                     │ │
│ │ Qlib因子表达式:                                      │ │
│ │ ($close / Ref($close, 20)) - 1                      │ │
│ │                                                     │ │
│ │ 📊 表达式解读:                                        │ │
│ │ • $close: 今日收盘价                                │ │
│ │ • Ref($close, 20): 20个交易日前的收盘价             │ │
│ │ • 计算结果: 20日累计收益率                          │ │
│ │ • 数值越大表示动量越强                              │ │
│ └─────────────────────────────────────────────────────┘ │
│                                                         │
│ 📝 因子表达式库:                                        │
│ ┌─────────────────────────────────────────────────────┐ │
│ │ • 20日动量: ($close / Ref($close, 20)) - 1          │ │
│ │ • 市盈率倒数: 1 / $pe_ttm                           │ │
│ │ • 30日波动率: Std($close / Ref($close, 1) - 1, 30)  │ │
│ │ • RSI指标: RSI($close, 14)                          │ │
│ └─────────────────────────────────────────────────────┘ │
│                                                         │
│ [保存因子] [添加到训练集] [语法检查]                      │
└─────────────────────────────────────────────────────────┘
```

### 示例对话场景

| 用户想法 | AI解读 | Qlib表达式 |
|---------|--------|------------|
| "最近涨得快的股票好" | 20日动量因子 | `($close / Ref($close, 20)) - 1` |
| "便宜的股票好" | 市盈率倒数因子 | `1 / $pe_ttm` |
| "波动小的股票好" | 30日波动率因子 | `Std($close / Ref($close, 1) - 1, 30)` |
| "成交量大的股票活跃" | 成交量相对强度 | `$volume / Mean($volume, 20)` |

### 技术实现
- **AI接口**: 集成GPT/Claude等大语言模型进行因子表达式生成
- **语法检查**: 使用Qlib内置的因子表达式解析器验证语法
- **代码编辑器**: 使用Monaco Editor提供语法高亮和智能提示

## 页面二: 模型训练配置 (Model Training)

### 功能概述
通过可视化界面配置模型训练参数，执行qrun命令进行模型训练。

### 核心流程
1. **数据配置**: 选择股票池、时间范围、数据频率
2. **因子选择**: 从因子库中选择要使用的因子表达式
3. **标签定义**: 设置预测目标（如未来5日收益率）
4. **模型选择**: 选择机器学习模型（LightGBM、XGBoost等）
5. **训练执行**: 启动qrun命令进行模型训练

## 页面三: 策略回测模块 (Strategy Backtesting)

### 功能概述
使用训练好的模型进行投资策略回测，模拟真实交易环境。本页面依赖其他页面提供的数据资源。

### 数据依赖
- **依赖页面一(AI因子助手)**: 获取因子表达式库，确保回测使用的因子与模型训练时一致
- **依赖页面二(模型训练)**: 选择已完成训练的模型文件，作为回测的预测引擎

### 核心组件
1. **因子确认**: 验证所需因子表达式是否可用（来自页面一）
2. **模型加载**: 选择之前训练好的模型（来自页面二）
3. **策略配置**: 设置交易策略参数（Top-K、多空等）
4. **执行器配置**: 配置交易成本、调仓频率等
5. **回测执行**: 运行backtest_daily进行历史回测

### Python回测代码生成

系统会根据配置自动生成如下的回测代码：

```python
# 自动生成的回测代码
import qlib
from qlib.contrib.strategy import TopkDropoutStrategy
from qlib.contrib.evaluate import backtest_daily

# 初始化 Qlib
qlib.init(provider_uri="~/.qlib/qlib_data/cn_data")

# 策略配置
strategy_config = {
    "class": "TopkDropoutStrategy",
    "module_path": "qlib.contrib.strategy.signal_strategy",
    "kwargs": {
        "model": "LightGBM_20250811_v1.pkl",
        "topk": 20,
        "n_drop": 5,
    },
}

# 执行器配置
executor_config = {
    "class": "NestedExecutor", 
    "module_path": "qlib.backtest.executor",
    "kwargs": {
        "time_per_step": "day",
        "generate_portfolio_method": "signal",
        "verbose": True,
        "track_data": True,
    },
}

# 回测配置
backtest_config = {
    "start_time": "2020-01-01",
    "end_time": "2023-12-31", 
    "account": 10000000,
    "benchmark": "SH000300",
    "exchange_kwargs": {
        "limit_threshold": 0.095,
        "deal_price": "close",
        "open_cost": 0.0005,
        "close_cost": 0.0015,
        "min_cost": 5,
    },
}

# 执行回测
portfolio_metric_dict, indicator_dict = backtest_daily(
    executor=executor_config,
    strategy=strategy_config,
    **backtest_config,
)
```

### 策略部署的实际应用方案

#### 1. 模拟交易阶段
- **纸上交易**: 不使用真实资金，完全模拟市场环境
- **实时验证**: 验证模型在最新市场数据上的表现
- **策略优化**: 根据模拟结果调整参数
- **风险评估**: 评估策略在不同市场环境下的稳定性

#### 2. 实盘部署选项

**A. 券商API接口**
- 对接主流券商的程序化交易接口
- 支持股票、基金、期货等多种资产类别
- 自动执行买卖指令，实现全自动交易

**B. 信号推送服务**
- 不直接交易，只推送买卖信号
- 通过邮件、短信、微信等方式通知用户
- 用户可以手动执行交易决策

**C. 第三方平台集成**
- 接入聚宽、米筐等量化平台
- 利用平台的交易基础设施
- 降低技术门槛和合规风险

#### 3. 风险管理机制
- **仓位控制**: 限制单股和总仓位上限
- **止损止盈**: 自动风险控制机制
- **实时监控**: 7x24小时策略运行监控
- **异常处理**: 异常情况下的应急机制

## 系统技术架构

### 前端技术栈
- **框架**: Vue 3 + TypeScript + Vite
- **UI库**: Element Plus  
- **图表**: ECharts
- **代码编辑**: Monaco Editor
- **AI集成**: OpenAI/Claude API

### 后端技术栈
- **框架**: FastAPI + Python
- **Qlib集成**: 直接调用Qlib库和qrun命令
- **任务队列**: Celery + Redis (处理长时间的训练和回测任务)
- **WebSocket**: 实时推送训练和回测进度
- **文件存储**: 本地文件系统存储模型和配置文件

### API接口设计

#### 因子助手相关
- `POST /api/factors/ai-generate` - AI生成因子表达式
- `POST /api/factors/validate` - 验证因子表达式语法
- `GET /api/factors/library` - 获取因子表达式库
- `POST /api/factors/interpret` - AI解读因子表达式

#### 模型训练相关  
- `POST /api/training/start` - 启动模型训练
- `GET /api/training/{task_id}/status` - 获取训练状态
- `GET /api/training/{task_id}/logs` - 获取训练日志
- `POST /api/training/{task_id}/stop` - 停止训练任务

#### 训练列表相关
- `GET /api/models/list` - 获取所有训练任务列表
- `GET /api/models/{model_id}/details` - 获取模型详细信息
- `POST /api/models/compare` - 模型性能对比分析
- `GET /api/models/{model_id}/download` - 下载模型文件

#### 回测相关
- `POST /api/backtest/start` - 启动回测任务
- `GET /api/backtest/{task_id}/status` - 获取回测状态  
- `GET /api/backtest/{task_id}/results` - 获取回测结果
- `GET /api/backtest/history` - 获取回测历史列表

#### 结果管理相关
- `GET /api/results/ranking` - 获取策略排行榜
- `POST /api/results/compare` - 策略结果对比
- `GET /api/results/{result_id}/analysis` - 获取详细分析报告
- `POST /api/results/{result_id}/optimize` - 获取优化建议

#### 策略部署相关
- `POST /api/deployment/create` - 创建策略部署
- `GET /api/deployment/{deploy_id}/status` - 获取部署状态
- `POST /api/deployment/{deploy_id}/start` - 启动策略
- `POST /api/deployment/{deploy_id}/stop` - 停止策略
- `GET /api/deployment/{deploy_id}/monitor` - 实时监控数据
- `POST /api/deployment/{deploy_id}/alert` - 设置告警规则

#### 券商接口相关
- `POST /api/broker/connect` - 连接券商接口
- `GET /api/broker/account` - 获取账户信息
- `POST /api/broker/order` - 下单接口
- `GET /api/broker/positions` - 获取持仓信息
- `GET /api/broker/orders` - 获取订单历史

这个完整的设计提供了从量化研发到实盘交易的全链路解决方案，帮助用户实现：
1. **研发阶段**: 因子开发 → 模型训练 → 策略回测
2. **验证阶段**: 模型对比 → 结果分析 → 策略优化  
3. **部署阶段**: 模拟交易 → 实盘部署 → 风险监控
